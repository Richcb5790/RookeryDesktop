Rookery, the visual Git client for Windows and Linux Every branch has a story.

Rookery is a Git GUI that draws your history like a star map, then isolates any branch to show where it came from, what flowed into it, and everywhere it landed. It keeps submodules in step, works with the hosts you already use, and hands conflicts to your own AI agent.

Visual commit graph

Your history,
charted like a star map.

  1. Every branch flies its own lane

    Each line of work keeps its lane and color from tip to fork, and a faint band in that color ties every commit to its branch, so you can follow it down the whole history at a glance.

  2. Merges curve home

    Merges arc back into the line they landed on. You can see where every piece of work ended up, not just that it did.

  3. Drag, drop, done

    Drop one branch onto another to merge, rebase, fast-forward or open a pull request, even into a branch you don't have checked out. Hover a commit to light up its line.

Hosting integrations

Docked with every place your code lives.

Connect GitHub, GitLab, Bitbucket and Azure DevOps, plus Jira and Trello for issues. Pull requests and issues show up next to the branches they belong to, and the Launchpad gathers everything waiting on you.

  • Pull requests beside branches

    Open pull requests sit on their branch labels in the graph, with description, reviewers, checks and conflicts a click away.

  • Drag a branch to open a PR

    Drop a branch on its remote and Rookery fills in your template. If the remote is behind, it pushes first.

  • Start work from an issue

    Pick an issue and get a branch named after it. The pull request that follows links back and closes it.

  • The Launchpad

    Reviews waiting for you, your open pull requests and issues assigned to you, from every account, in one tab. The Harbor tells you what's waiting there.

  • Clone anything you can see

    Search to clone finds every repository your account can see, not only your own: another team's, an owner/ prefix, or an exact name.

Isolate a branch

Shine a light on any branch's story.

  1. Real histories get crowded

    Seven lines of work, merges going every direction. Which one is yours, and where did it end up?

  2. Isolate it

    One click and everything unrelated falls away. The branch moves to the first lane with only what it touched: its own commits, what merged in, and where it merged out.

  3. Read the map

    The same story as a map: created from main, feature/sensors merged in, then shipped to develop and main.

  4. Trust the timeline

    Every fact says where it came from: recorded by Rookery, the branch reflog, a merge message, or inferred from the graph. A branch you pulled down from its remote still shows its whole line, back to its real base.

Merge conflicts

Pick the lines.
Keep both stories.

Yours and Theirs sit side by side over an editable Result. Click a line to take it, from either side, in any order. The Result builds as you go.

  • Line by line, or all at oncePick single lines, take a whole side, or take neither. Every conflict shows whether it's resolved, unresolved or edited by hand.
  • Opens where the trouble isThe editor takes the full width of the window and scrolls to the first conflict. A progress bar counts them down.
  • Know before you mergeRookery predicts conflicts in the merge preview, before anything is touched.
  • Submodule pointers settle by commitWhen one side contains the other, Rookery takes the newer commit. When they diverged, merge them in the submodule with one click.

Local AI agents

Bring your own agent.
Keep the final say.

Rookery has no AI of its own and no service behind it. It hands the work to the coding agent you already use, signed in as you, and shows you what it proposes: a conflict resolved, a commit explained, a commit message written.

Private by design

            
No account. No cloud.
Just you and git.

            

              Rookery runs entirely on your computer. There's no Rookery account and no service behind it, and git itself does the work.
            

          

          

            
    
              
  • 
                
                
    Nothing to sign up for
    
                
    Rookery has no backend of its own. There's nothing to sign in to, and your repositories stay where they are.
    
              
    • 
              
  • 
                
                
    Runs real git
    
                
    Every command goes through the git CLI, so hooks, signing, LFS and credential helpers behave exactly as they do in your terminal.
    
              
    • 
              
  • 
                
                
    Never stores git credentials
    
                
    Git Credential Manager or ssh-agent handle them. Tokens for connected accounts are encrypted with your OS keychain and never reach the window.
    
              
    • 
              
  • 
                
                
    Signed releases
    
                
    The Windows installer is code-signed. The Linux AppImage and .deb are GPG-signed, with checksums published beside them.
    
              
    • 
              
  • 
                
                
    Updates only on request
    
                
    Nothing checks in the background. An update installs only when a manifest signed with Rookery's own key vouches for every file, and never downgrades.
    
              
    • 
              
  • 
                
                
    Agents read, you decide
    
                
    Local agents run read-only by default. They propose, and nothing is written until you save it.

Questions

            
Before you launch.

            
Short answers to what people ask first.

          

          

            

              
What is Rookery?

              
Rookery is a desktop Git client, a Git GUI for Windows and Linux. It shows your repository as a visual commit graph and covers everyday Git: staging, committing, branching, merging, rebasing, stashing and pushing. On top of that it adds branch lineage, which tells the story of any branch, and submodule sync, which carries each operation through every submodule.

            

            

              
Is Rookery free?

              
Rookery is free to download. There's no account to create, no subscription and nothing to sign in to.

            

            

              
Which operating systems does Rookery run on?

              
Windows 10 and 11 (64-bit), with a signed installer, and Linux, as an AppImage or a .deb for Debian and Ubuntu. A macOS build is planned and is waiting on Apple code signing.

            

            

              
Does Rookery work with Git submodules?

              
Yes, and it's one of the things Rookery was built for. With submodule sync on, creating, checking out, merging, pushing, pulling, renaming, deleting and rebasing a branch carry through every submodule, at any depth. Merges happen submodule-first and the parent's pointers resolve to the merge results. Every step is journaled and can be rolled back.

            

            

              
Which Git hosts and issue trackers does it connect to?

              
GitHub and GitHub Enterprise Server, GitLab.com and self-managed GitLab, Bitbucket Cloud and Data Center, and Azure DevOps, for repositories and pull requests. Issues come from GitHub, GitLab, Azure Boards, Jira and Trello. Rookery also works with any plain Git remote.

            

            

              
Does Rookery have AI built in? Where does my code go?

              
Rookery has no AI of its own and no service behind it. If you set one up, it uses a coding agent already installed on your computer, such as Claude Code, Codex, Copilot CLI or Gemini CLI, signed in as you. The agent talks to its own provider exactly as it does in your terminal, and by default it can only read. Without an agent, nothing is sent anywhere.

            

            

              
I use GitKraken, Sourcetree, Fork or GitHub Desktop. What's different?

              
The everyday tools are where you'd expect them: a commit graph, staging down to the line, interactive rebase, worktrees, Git LFS, Git Flow and a built-in terminal. What's different is Isolate, which filters the graph down to one branch's story; submodule sync; AI through the agent you already have instead of a hosted model; and no account or cloud service at all.

            

            

              
Do I need Git installed?

              
Yes: Git 2.40 or newer on your PATH, or point Rookery at it in Preferences. Rookery runs the real git command line for everything, which is why your hooks, commit signing and credential helpers keep working unchanged.

            

            

              
How does Rookery update?

              
When you ask it to. Preferences → Updates → Check for Updates looks for a newer release, downloads it, verifies its signature and offers to restart. A .deb install is pointed to the release page instead. Nothing checks in the background.
